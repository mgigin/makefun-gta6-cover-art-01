Vice Panel Studio turns your own photos into GTA-style multi-panel cover art, entirely in the browser and fully offline. Choose a panel layout, drop in your pictures, set a caption in a heavy display font with the classic outlined look, and export the finished cover as a PNG at 1080×1080, 1080×1350 or 1920×1080. Nothing is uploaded and no account is needed — your photos never leave your machine.

## Run it

```sh
node serve.ts
```
